# Markdown 工作区与复盘

侧栏「文件」可创建文件夹、新建、阅读、编辑和下载 `.md`。AI 使用 Tools 管理中的 `list_files`、`read_file`、`create_directory`、`write_file`，通过同一存储读写。

文件是保存在 `engine/data/desk.db` 的虚拟文件条目，随数据库备份与恢复；不会映射到服务器任意磁盘路径。下载功能可导出独立 Markdown 文件。只允许相对路径，单文件最多 128 KiB，工作区最多 2000 项、32 MiB。

新建传 `revision: 0`；修改先读取，再传当前版本及完整正文。版本冲突保留原文件和界面草稿，需要重读合并。未提供删除功能。文件内容在界面按纯文本编辑，不执行 HTML 或脚本。

工作区根目录 `INVEST.MD` 是常驻工作指令。引擎在持续运行和面板对话的每次正常模型请求前读取，渲染策略参数，并按「角色定义 → INVEST.MD → Tools」顺序组成 system。无需模型先调用读文件；文件内容不会随最近对话裁剪而丢失。AI 或用户保存修改后下一轮请求会刷新远程代理配置；当前已经发出的请求保持原上下文。其他文件仍按需读取，不自动提升为指令。

启动迁移会建立 `复盘/索引.md` 和 `INVEST.MD`。原 System 中已明确标注的角色定义保留；非角色部分、开始运行要求与未调用工具时的处理要求原样迁入 INVEST.MD，未识别的文字保留在文档中。旧配置和已存在的 INVEST.MD 均备份；已有文档正文保留，迁移内容追加。文件、提示词与工具说明在同一事务更新，失败不会留下半迁移。后续重启不覆盖用户修改。

「模型」页面仅保留角色定义、面板对话与等待结束场景；原开始运行、未调用工具设置合并到 INVEST.MD。运行时仍会通知启动和未调用工具事件，具体处理规则来自常驻文档。「模型」中的 INVEST.MD 编辑器与「文件」编辑的是同一份文档，均校验 revision；策略档案追加到文档草稿，不替换角色定义或原有工作规则。

INVEST.MD 必须为非空文件，不能创建为目录。读取失败时请求报错，不静默忽略工作指令；单文件和工作区容量限制仍适用。文档可以指导判断和研究，不能改变代码执行的交易权限或硬风控。

系统要求代理核查新增成交结果，每笔已确认净亏损或有证据的判断错误单独创建 `复盘/YYYY-MM/日期-环境-币种-事件ID.md`，写明事实、当时依据、结果、根因、改进和验证方式，并更新索引。实际保存须以文件工具返回及回读为准；资料不足记录为待核实，不捏造历史。

复盘发现、撰写和回看由模型遵循系统指令执行，并非后台独立亏损检测器。代理停止或模型网关不可用时不会自动生成新复盘；文件页面仍可使用。工具具备后端路径、大小、版本和持久化校验。

验证：`go test ./...`、`go vet ./...`、`npm.cmd run build`、`npm.cmd test`；浏览器文件测试 `node --test tests/files.browser.mjs`，使用 `DESK_PLAYWRIGHT_MODULE` 指向已有 Playwright 包，可用 `DESK_TEST_URL` 指定本机前端地址。
