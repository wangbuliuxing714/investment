# AI 策略回测与迭代流程

状态：流程设计，尚未实现自动回测与迭代工具。

## 核心顺序

从已有策略出发：冻结当前策略版本 → 回测 → 复盘并定位问题 → 提出修正 → 记录问题与修正原因 → 生成新策略版本 → 再次回测，重复此流程。

AI 负责调用工具、解释证据和提出修改；回测引擎负责执行策略、模拟成交和计算指标；Markdown 工作区保存策略说明、实验索引和复盘。修改候选策略不自动替换正在运行的交易策略。

## 1. 建立基线

- 读取已有策略；将文字描述中的入场、退出、仓位和失效条件明确为可执行规则。无法明确的条件须标记，不得擅自补全后声称是在回测原策略。
- 保存不可覆盖的策略快照，分配 strategy_version，并记录父版本。
- 固定交易市场、币种、周期、数据版本与时间范围、初始资金、手续费、滑点、资金费率和成交假设。
- 若策略由大模型逐步决策，还需冻结模型、提示词、工具与回放配置，记录每步输入和输出；历史知识泄漏和模型输出不确定性须单独说明。
- 预先确定评价标准、允许调整的内容、迭代轮数/时间/费用上限与停止条件。

## 2. 运行回测

- 每次回测分配独立 run_id，关联冻结的策略版本及完整配置。
- 按时间推进，只允许使用决策时已知的数据；指标预热和成交时点必须一致。
- 保存交易明细、费用明细、资金曲线、风险指标、运行状态及数据缺口。
- 回测失败或数据不足是运行问题，不得伪造策略表现，也不得据此认定交易规则有缺陷。

## 3. 复盘并定位问题

- 每个问题分配 issue_id，引用具体 run_id、交易/时间区间、指标或日志证据。
- 分开记录已观察事实、根因假设、未知项及待验证内容。
- 区分数据错误、回测/执行错误、交易规则问题，以及符合预期的正常亏损；不要求每次回测必须找出策略错误。
- 除亏损外，也检查回撤、成本、收益集中、交易频率、跨时期稳定性及相对基线表现。
- 不把事后可见的信息写成当时能够执行的交易依据。

## 4. 提出并记录修正

在开始下一次回测前，保存变更记录，至少包含：

| 字段 | 内容 |
| --- | --- |
| change_id | 本次修改唯一标识 |
| parent_strategy_version | 原策略版本 |
| candidate_strategy_version | 候选版本 |
| source_run_ids / issue_ids | 导致修改的回测和复盘问题 |
| evidence | 支撑问题判断的具体证据 |
| root_cause_hypothesis | 当前认为的原因，标明未证实部分 |
| before / after | 修改前后明确规则或参数 |
| reason | 为什么该修改可能解决所引用的问题 |
| expected_effect | 预期改善及可能牺牲的表现 |
| validation_criteria | 怎样判断修正有效、无效或有害 |
| created_at | 修改时间及所在时区 |

尽量每次围绕一个可检验假设修改；相互依赖的修改须说明原因。不覆盖旧策略、旧回测或旧复盘，也不在看到结果后改写原始修正理由。

## 5. 再次回测并比较

- 用同一数据和成本口径比较候选与父版本，保留两份报告及全部尝试记录。
- 检查原问题是否改善、是否出现新问题，以及是否只是牺牲其他时期或风险指标换取局部收益。
- 记录候选状态：待验证、保留、拒绝或证据不足；收益提高不自动代表修改通过。
- 不通过时继续从证据复盘，可回退或尝试其他修正，不把每次修改都强行设为新基线。

## 数据划分与停止

- 按时间划分研究区间、验证区间和保留测试区间；日常修正围绕研究数据进行。
- 反复用于选策略的验证数据已参与开发，须记录使用次数；不能继续称为独立检验。
- 保留测试在候选冻结后使用；若根据其结果继续修改，应将其视为已使用数据，后续需要新的未见数据或向前模拟交易。
- 可采用向前滚动验证；每个时间窗口只能使用其之前的数据开发规则。
- 达到预设预算、没有充分证据支持修改或持续无法改善时，保存当前结论并停止；不无限循环直到历史收益变好。
- 研究循环结束后的独立验证、模拟运行与交易版本启用另行记录，研究循环自身不调用真实下单。

## 与现有系统的关系

现有能力包括 Markdown 工作区读写、历史行情分页、部分指标及实际成交查询。工作区 revision 是并发编辑校验，不等于保存完整历史版本；实验快照和版本档案需要额外实现。

仍需实现：历史数据集缓存与完整性检查、可执行策略格式/运行接口、回测引擎、实验和版本存档、比较报告，以及 AI 可调用的研究工具。Markdown 保存研究材料和结果索引；大规模行情、成交明细及资金曲线由数据层保存并提供可校验引用。
